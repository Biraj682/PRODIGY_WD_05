# Weather App (PRODIGY_WD_05)

A dynamic and responsive weather web application designed to provide users with real-time weather information. By integrating the OpenWeatherMap API, this app allows users to search for any city and instantly view current weather conditions, temperature, and climate details. 

**Key Features:**
* Real-time data fetching via OpenWeatherMap API.
* Clean and intuitive user interface.
* Responsive design for both desktop and mobile viewing.
